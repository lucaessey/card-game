# Untitled Card Game

Play at https://lucaessey.github.io/card-game/

This repository contains built website assets. Current build: ee6e96c9839758974d8927b0. Catalog v8 contains 336 cards.

Progress is saved in this browser on this device. All six pack rarities are available with earned coins after their level unlocks; purchases require a connection. CPU play, earned coins, tutorials, collection, team editing and offline downloads are supported. Cross-device accounts are a later milestone.
